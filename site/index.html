Inspect the installer ↗Manual installation ↗

Requires the plugin-capable Omarchy shell, Git and Python 3. Optional integrations are installed separately. Native Linux plugin; no Windows or macOS build.

A few useful things
Is this a standalone app or a plugin?+

Oma Owl is a native Omarchy shell plugin with an application-menu launcher and a full-screen workspace. It runs inside Quickshell and needs the Omarchy desktop. The website preview is a small interactive illustration, not the installed app.

Do I need any connected accounts?+

No. Local tasks, daily notes, the focus timer and insights work without accounts. Todoist, OmaCal, HEY, Codex and Voxtype provide optional features; their own accounts, installations and service terms apply.

How do I update it?+

Run omarchy plugin update kosta.omaowl. Your notes, local tasks and connection settings live outside the plugin directory. See the README for backups and removal.

Can I use my own keyboard shortcut?+

Yes. Bind omaowl command in your Hyprland configuration. The installer leaves your existing shortcuts alone. You can always open Oma Owl from the application menu or bar.
